# Power-BI-Inventory-Analysis-Dashboard

## Project Overview
This project focuses on analyzing inventory data using Microsoft Power BI. The dashboard provides insights into product availability, demand, and pricing through interactive visualizations, DAX calculations, and filters.

## Objectives
- Analyze product availability and demand across different dates.
- Compare inventory data across products.
- Use DAX to create calculated measures for data analysis.
- Apply filters to explore specific products and data categories.
- Present meaningful insights through an interactive dashboard.

## Tools & Technologies
- **Microsoft Power BI** – Dashboard creation and visualization.
- **DAX (Data Analysis Expressions)** – Creating calculations and measures.
- **Power Query** – Data preparation and transformation.
- **CSV Files** – Source datasets.

## Datasets
- **Test Environment Inventory Dataset:** Contains order dates, product IDs, availability, and demand.
- **Products Dataset:** Contains product IDs, product names, and unit prices.

## Key Features
- Interactive charts and visualizations for inventory analysis.
- DAX measures for calculating and analyzing key metrics.
- Filters and slicers to explore data based on selected criteria.
- Relationships between inventory and product datasets using Product ID.
- Product-level analysis of availability and demand.

## Key Learnings
- Data cleaning and transformation using Power Query.
- Data modeling and relationships in Power BI.
- Writing DAX formulas and creating measures.
- Using filters and slicers for interactive data exploration.
- Building dashboards to communicate data insights.

## How to Run
1. Download or clone this repository.
2. Open `udemy BI project.pbix` using Power BI Desktop.
3. Update the CSV source paths if required.
4. Refresh the data and explore the dashboard.
